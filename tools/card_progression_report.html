What this curve can tell us

  • These are heuristic bots, not estimated human win rates. Compare several policies and use human playtests to choose the desired difficulty targets.
  • Card-set averages assume every tested set at that count is equally likely. Actual exploration order can be very different; inspect the weakest sets as well as the curve.
  • Per-set uncertainty uses Wilson intervals. Count-level uncertainty resamples seeds in clusters so repeated outcomes across card sets are not mistaken for independent trials.
  • Identical outcomes can produce a zero-width bootstrap interval. This does not establish a zero effect or guarantee wins outside the tested seeds.
  • Timeouts are unresolved, not losses. A seed with a timeout in any tested set is excluded from that count's paired curve estimate; all timeout counts remain visible.
  • Pacing is the median across resolved matches. Each marginal comparison changes only the collected set; opponent rules and tuning must remain constant throughout the study.
